# README screenshots

These images were captured from the native SwiftUI application at source revision
`14063ac` on macOS. The release native shell used the documented source Python
helper during capture.

Each workspace has English (`en`), Simplified Chinese (`zh-CN`), and Japanese (`ja`)
versions: album library, album details, import preparation, and Removal Package.
The library views show a connected iPod. Import preparation uses generated demo
audio and artwork. No import, removal, or restore was executed for the screenshots;
the temporary import queue and Removal Package were cleared afterward.

Published WebP files have coarse mosaic over device names and visible personal
paths. Empty space outside the application was cropped from library and import
views. No UI content was fabricated. Unredacted originals stay in the ignored
`.scratch/` directory and must not be published.
